# 攀登生命的高峰 - 四年級寫作引導與互動學習網頁 (chinese4-06)

專為國小四年級國語文第 6 課《攀登生命的高峰》（江秀真故事）設計的讀寫結合與寫作引導互動學習網頁。

## 功能特色

1. **課文精讀與數位劃線筆**：段落核心意涵與金句標記，支援 html2canvas 匯出劃記長圖。
2. **情節脈絡事件排序遊戲**：互動卡牌拖曳排序江秀真挑戰聖母峰的關鍵時間軸。
3. **典範名人九宮格故事拆解**：江秀真、齊柏林、沈芯菱等人物故事結構分析。
4. **靈感金句好詞大轉盤**：動態轉盤抽取修辭佳句與四字成語，活化寫作素材。
5. **四段式寫作鷹架引導**：從起因、經過、高潮到感悟，逐步引導學童撰寫自己的挑戰故事。
6. **作文成稿美化與列印**：自動排版稿紙格式，支援長圖下載與列印輸出。
7. **10 題閱讀理解評量**：包含音效、即時解析與學習評量。
